# TitiTest

## TitiSnake

Snake en un seul fichier (`index.html`), sans dépendance, jouable au clavier et au tactile.

- Swipe, pad ou flèches / ZQSD / WASD pour diriger
- Tap ou Espace pour pause
- Record conservé en local

## Abyss Hub // DOORS

Script Roblox DOORS (`doors/AbyssHub.lua`) pensé pour Delta Android : UI tactile maison (bouton flottant « A », onglets Visuels / Joueur / Entités / Auto / Infos), ESP par catégorie, Fullbright, No Fog, Speed, FOV, alertes d'entités, interaction instantanée, auto-ramassage de l'or.
