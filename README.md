# TitiTest

## TitiSnake

Snake en un seul fichier (`index.html`), sans dépendance, jouable au clavier et au tactile.

- Swipe, pad ou flèches / ZQSD / WASD pour diriger
- Tap ou Espace pour pause
- Record conservé en local

## Abyss Hub // DOORS

Script Roblox DOORS (`doors/AbyssHub.lua`) pensé pour Delta Android, à coller directement dans l'exécuteur.

- 7 onglets : ESP, Monde, Joueur, Entités, Auto, Couleurs, Réglages
- ESP : portes, clés/leviers, objectifs, objets, or, tiroirs/coffres, cachettes, entités, joueurs (contours, noms, distance, arc-en-ciel)
- Fullbright, No Fog, anti-flou, speed, saut, FOV, alertes + historique d'entités, anti-Screech
- Interaction instantanée, portée x1.5, auto-ramassage or/objets
- Thèmes et couleurs ESP personnalisables, config sauvegardée automatiquement
